Rules

This server is meant to be a fun, relaxing place. If what you're doing makes it less fun or less relaxing for other people, it doesn't belong here.

Be nice to each other

  • Don't make the game worse for anyone else.
  • Keep builds, signs and chat family friendly. No obscene builds or art.
  • Swearing is fine in moderation. Don't overdo it, and never aim it at someone.
  • Don't take things that aren't yours.

Pranks are fine, griefing isn't

  • A prank should take about as long to clean up as it took to set up, or less. Anything more is griefing.
  • Prank people you know will take it well.

Keep an eye on lag

  • You don't need to worry much about this one. If something you've built is lagging the server badly, the admin may step in so it stays smooth for everyone.

Don't cheat

  • No hacked clients and no x-ray, whether it comes from a mod or a resource pack.
  • Even if it feels like it only affects you, one person cheating can ruin the server for everyone else.
  • Autoclickers for XP farms are fine.

If something goes wrong

Breaking the rules can get you a warning or a ban, at the admin's discretion. If something on the server is bothering you, message DaCubeKing in game or @DaCubeKing on Discord.
