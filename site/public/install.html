How to join

Any unmodded Minecraft Java Edition 26.3 client can join. The modpack is optional and only adds things on your side.

Before you start

The server has a whitelist. Send the admin your Minecraft username so they can add you.

Play with plain Minecraft

The quickest way in. Use the official launcher or any launcher you already have.

  1. Open the launcher, pick Java Edition and choose version 26.3 (Latest release, if 26.3 is current).
  2. Start the game and click Multiplayer, then Add Server.
  3. Enter play.dacubeking.com as the server address and click Done.
  4. Select the server and click Join Server.

Any mods you already use on 26.3 are fine too, as long as they're client-side, like Sodium or a minimap.

Or install the modpack

Adds faster rendering, shader support, voice chat, richer sound and Voxy, which draws terrain far past your normal render distance using data the server sends. The server is already in your server list.

Download the modpack (.mrpack)

With Prism Launcher

  1. Install Prism Launcher and sign in with your Microsoft account.
  2. Click Add Instance, then Import.
  3. Paste the modpack link, https://pack.dacubeking.com/dacubeking-SMP.mrpack, or browse to the file you downloaded. Click OK.
  4. Right-click the new instance, choose Edit, then Settings, and set the maximum memory to at least 6 GB.
  5. Launch it and join dacubeking SMP from the Multiplayer screen.

With the Modrinth App

  1. Install the Modrinth App and sign in with your Microsoft account.
  2. Download the modpack file, then drag it onto the Modrinth App window (or open it with the app).
  3. In the instance's settings, under Java and memory, set memory to at least 6 GB.
  4. Click Play and join dacubeking SMP from the Multiplayer screen.

When the pack is updated, download it again from the same link and import it as a new instance. Your settings in the old instance aren't touched.

Using the modpack

  • Voice chat: press V to open voice chat settings and pick your microphone. Talk with push-to-talk (Caps Lock by default) or switch to voice activation. Players without the mod can't hear or be heard.
  • Shaders: open Options, then Video Settings, then Shader Packs. Pick one from the list. Complementary Reimagined is a good start, and MakeUp Ultra Fast is the lightest if your frame rate drops.
  • Distant terrain: Voxy fills in the horizon on its own as you play. Keep the normal render distance around 8 for the best frame rate.
  • Sound: biomes and caves have their own background ambience, sounds echo in caves and are muffled through walls, and footsteps and rain sound different depending on what they hit. If the ambience is too much, turn down Ambient/Environment under Options, then Music & Sounds.
  • Resource packs: Vanilla Tweaks (dark menus, varied block textures, shorter grass and more), a texture per enchanted book, connected glass and voice chat's black icons are on by default. Change them under Options, then Resource Packs.
  • Zoom: hold C.

If you can't connect

  • "You are not white-listed on this server": ask the admin to add your username, then try again.
  • "Incompatible client" or "Outdated client": switch your game version to 26.3.
  • The modpack crashes on launch: re-download it from the link above and import it as a new instance.
